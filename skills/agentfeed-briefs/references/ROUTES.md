# Routes, prices and pass terms

Generated by scripts/generate.mjs from the AgentFeed code. Do not edit by hand. The live 402 challenge of each route is the authority on its price; prices can change.

Service: https://x402.ochinimus.app. Header for a key or pass: `X-AgentFeed-Key: afk_...` (or `Authorization: Bearer afk_...`).

## Morning brief: `GET /api/morning-brief`

- Price: $0.03 per call (x402, USDC), tool name `get_morning_brief` over MCP
- Free sample: `https://x402.ochinimus.app/api/sample/morning-brief`
- Question it answers: What changed overnight in BTC, ETH, SOL and HYPE, and what is the one level to watch?

Use when an agent needs the overnight picture for BTC, ETH, SOL and HYPE in one answer. Returns the last 8 hours ranked by how abnormal each item is: price move against the coin's own usual 8-hour move, funding, open interest, liquidations (total, long/short split, biggest print), Fear and Greed, today's macro releases with UTC times, and the nearest liquidation cluster as the level to watch. A stale source is left out and named; with no sampler it answers 503, never billed.

## Move alert: `GET /api/move-alert`

- Price: $0.02 per call (x402, USDC), tool name `get_move_alert` over MCP
- Free sample: `https://x402.ochinimus.app/api/sample/move-alert`
- Question it answers: Which Hyperliquid perps moved unusually, and was it the calendar or unexplained flow?

Use when an agent needs to know which Hyperliquid perps moved unusually. Returns each coin whose 5-minute, 1-hour or 4-hour price move, or 1-hour open-interest change, is past its own measured tail (tiers from the coin's own history, sample size printed), labelled event-driven when a scheduled FOMC, CPI, NFP or PCE release explains it. An empty list is a valid answer. Stale inputs answer 503, never billed.

## Anomaly flag: `GET /api/anomaly-flag`

- Price: $0.02 per call (x402, USDC), tool name `get_anomaly_flag` over MCP
- Free sample: `https://x402.ochinimus.app/api/sample/anomaly-flag`
- Question it answers: Is anything abnormal in funding, liquidations or open interest across the perps right now?

Use when an agent needs one check for what is abnormal across Hyperliquid perps right now. Returns funding, liquidation and open-interest anomalies in one ranked list, using the thresholds of /api/market-state, or nothing abnormal with what was checked. If a source is stale and nothing else was found it answers 503 rather than an all-clear, and is never billed.

- Terms as the purchase response states them: a 30-day brief pass for a flat $25, good only on /api/morning-brief, /api/move-alert, /api/anomaly-flag, non-refundable, cannot be topped up (buy another when it ends); the key is a bearer secret: anyone holding it uses the pass; abuse means revocation.
